# OHM TAPE · 磁带

一个单页的三维磁带展示页面。磁带模型完全由代码程序化生成（没有外部模型文件、没有外部贴图、没有网络请求），
材质按物理量设定，支持鼠标旋转 / 缩放 / 双击复位，并带有一套围绕它的动画与交互。

界面做成一台**档案终端**：页头是机型，右侧是当前档案的正文，底部是控制台。
这台磁带被拆成六条档案——整机，加上拆解图里的五个零件——读一条零件档案，机身会打开、
该零件留在真实材质上、其余零件退成幽灵，镜头同时切到它自己的机位。规格表里的数字基本来自模型本身。

## 打开

直接双击 `index.html` 即可（已打包成 `dist/app.js`，`file://` 下可以正常运行）。

## 音乐

磁带里装的是 **Matryoshka — Sacred Play Secret Place**（专辑 *Laideronnette*）。
源文件是 24bit/192kHz 的 FLAC（187 MB），已转成 44.1kHz / VBR ~169 kbps 的 MP3（6.4 MB，约为原文件 1/29），
放在 `assets/sacred-play-secret-place.mp3`。

**这个仓库里不含那首歌**：它是 Matryoshka 的商业录音，公开仓库不再分发（`assets/` 已写进 `.gitignore`）。
克隆下来想让它出声，把任意音频丢成 `assets/sacred-play-secret-place.mp3` 就行；放别的名字也可以——直接点页头的
**ADD MUSIC** 装一首自己的，或者改 `src/main.js` 顶部的 `TRACK.src`。完全没有音频时页面会走
「音频加载失败 · 仅走带动画」那条降级路径，走带与倒带照常演，只是没有声音。

原始转码命令（用任何带 libmp3lame 的 ffmpeg）：

```bash
ffmpeg -i "Sacred Play Secret Place.flac" -vn -map 0:a:0 \
  -af "volume=-1.5dB" -ar 44100 -c:a libmp3lame -q:a 2 \
  -metadata title="Sacred Play Secret Place" -metadata artist="Matryoshka" \
  -metadata album="Laideronnette" assets/sacred-play-secret-place.mp3
```

### 装一首自己的

页头的 **ADD MUSIC**（或按 `O`，或把音频文件直接拖到页面上）选一个本地文件，磁带就换成它。
曲名 / 艺人 / 专辑读的是文件自己的 ID3 标签（`src/tags.js`：v2.2 / 2.3 / 2.4 与 v1 都认，UTF-16 与 UTF-8 都认），
没有标签就用文件名。跟着一起变的还有：标签上的手写体标题与 MINUTES 带长、页头的型号铭牌（`C—05` → `C—01` …）、
中间的曲目条、右下角计数器的总长、浏览器标签页的标题。

换带不是一次硬切。新的印刷先画在标签上方那层同形状的副本上，再由一条从左扫到右的写头放出来
（`cassette.js` 的写头 / `main.js` 的 `updateLabelSwap`），机身同时被压下一点再回弹，配一声走带开关声；
写头扫完的那一刻整页才一起换成新的一首，所以看不到"文字跳了一下"。

再放一首就是替换上一首（这台机器只有一盘带）；刷新页面回到出厂那一首；REINITIALIZE 也把它放回去。
文件不上传到任何地方，也不会被存进浏览器——它只是被 `<audio>` 指着的一个 blob URL。

### 换掉出厂曲目

把新文件丢进 `assets/`，改 `src/main.js` 顶部的 `TRACK`（`title / artist / album / src`）
和 `createCassette({ minutes: '05' })` 里的带长标注，然后双击 `重建.bat`。
曲名会自动写到标签的手写体标题上。

放完一首会自动快速倒带（约 4 秒，计数器变铜色），倒完从头再放，循环。

## 交互

页面是一台档案终端：这台磁带被拆成 **六条档案**（整机 + 五个零件），`↓↑` 翻档案，`←→` 换机位，
`回车`（或点「读取」、或再点一次已选中的那一行）读取。**读取是唯一会改变画面的动作**——
浏览只移动游标，镜头不会在你读的时候从底下动起来。

| 操作 | 效果 |
| --- | --- |
| `↓` `↑` / 点列表 | 前后翻档案：整机 / 烟灰上壳 / 观察窗 / 自攻螺钉 / 磁带 / 轮毂与带盘 |
| `←` `→` | 切换机位：等轴 / 正视 / 俯视 / 细节特写。切到「细节特写」时镜头推得很近，磁带会伸到右边那一栏底下，所以**「细节特写」就是"面板收起"的机位**：选中它整块面板直接自己整个收起（不是先变短再收）、只留编号与读取按钮，不用点收起；离开这个机位自动展开回来。在那儿手动展开的话退回到收回 34%、规格表留着那一档 |
| `回车` / 读取按钮 | 读取当前档案 |
| `I` / ARCHIVE INDEX | 打开总目录：六条档案连规格一起列出，点某条的标题直接读取 |
| `O` / ADD MUSIC | 换一首自己的：选本地音频文件，标签被重新写一遍（见「音乐」）。拖一个音频文件到页面上效果相同 |
| `,` / SETTINGS | 打开设置页（见「设置」）。齿轮在悬浮时转 1/4 圈并放大，打开期间保持转过去的状态 |
| `Esc` | 退一层：总目录开着就关目录，否则合上拆解，否则展开收起的面板 |
| 收起详情 | 折叠右侧正文（只留编号与读取按钮）。两拍：正文先上下合拢，随后整块内容向左边缘收回 60%——横线是面板的左边缘，面包屑、编号、读取按钮都坐在这条边上，所以它们跟着线一起走，线变短而字不掉队。同时磁带向画面中间挪（`viewShift` 0.155 → 0.05），把腾出来的地方占上。展开是同样两拍倒放 |
| 拖动 | 旋转（带惯性阻尼；松手 3 秒后缓慢自转） |
| 滚轮 / 双指捏合 | 推拉镜头。**推近时面板跟着一起变短**：静止时本来就让出 20%，从默认机位（radius 33）推到最近的 11，再线性让出 30%（`--retract` = 20% + `--give`）。**推到接近最近（让出 45%，线只剩自己长度的 55%）时面板才自动整个收起**——再往里确实没剩多少档案可读，不如照「收起详情」那样让开；**往回拉一格（让出降到 45% 以下）就自动展开回来**——收和展是同一条线，滚轮回到刚才离开的位置，面板就回到刚才的样子。判定做在**越过**那条线的瞬间，不是看滚轮停在哪一侧：否则「收起详情」会按不动（每帧都会被滚轮按回去）；两次越线之间，手工收起或展开的状态照旧保留，不在临界点上跳。阻尼走的就是折叠那条 `margin-left` 过渡，滚轮还在转的时候只是在挪一个会动的目标；往回拉超过默认机位也不再变长，因为退开不是面板该占画面的理由。正文窄到 330 px 以下时换成单列，REFERENCE AREA 先让位——那六条档案底部游标和总目录里都有 |
| 双击 | 回到默认机位 |
| `空格` | 走带 / 暂停：两轮同向转动、带盘半径按带面积守恒实时变化、计数器 = 歌曲进度（放完自动快退重放），并叠加一层磁带底噪与马达嗡声 |
| `E` / 拆解 | 分层展开上壳 / 玻璃 / 标签 / 带芯 / 下壳，并显示五条引线标注 |
| `F` / 翻面 | 整体翻转 180°，看 SIDE B（螺钉、轮毂孔、背面标签） |
| `M` / 静音 | 只关掉声音，走带动画继续 |
| 喇叭上滚轮 | 调音量：5% 一档，默认 30%。图标上会浮出当前档位，弧线也跟着走（过半亮两道）；滚到 0 就是静音，往上滚第一格解除静音。滚轮在这个按钮上被就地截住，不会同时推拉镜头 |
| `A` / 巡览 | 自动环绕开关 |
| 右上三格 | 换光环境：暗房 / 影棚 / 动画。环境光、背景、灯位、后期参数整体过渡；「动画」额外开启三渲二描线分层 |
| REINITIALIZE | 回到初始状态：整机档案、等轴机位、影棚光环境、停止走带 |

`prefers-reduced-motion` 下整套动画退成"切"：不放片头、不呼吸浮动、镜头换机位直接落位、
拆解与幽灵渐变不插值、面板折叠与随镜头变短、主题切换不做过渡。状态变化本身都还在，只是不再一路走过去。

### 读取一条零件档案会做什么

三件事同时发生，目的是让"这张图纸"和"这台实物"是同一个东西：

1. **分层展开**，把该零件**留在真实材质**上，其余零件**渐变成**一层暖灰的半透明幽灵；
2. **引线只留该零件那一条**，其余标注和引线一起隐藏；
3. **镜头切到该档案自带的机位**。拆解后零件会朝镜头方向抬起，所以每条档案的机位都比看上去需要的更远。

档案里的规格（材料、壁厚、带速、卷径……）基本直接对应模型里的 `DIM`。

**幽灵是渐变过去的，不是切过去的。** 幽灵的每一条特征——灰、平、透——都是靠动画材质自己的
uniform 走到的：颜色、粗糙度、金属度、清漆、法线强度一起走到目标值，不透明度最后跟着下去
（`paintGhost`）。旧版是直接换成一块半透明的灰料，在一段缓入的运镜和一段缓出的拆解中间，
那一下硬切看起来像卡了一帧。

渐变用的材质副本必须**每个 mesh 一份**：原件是共享的（`M.shell` 被好几个零件同时指着），
改一个就会改一片。副本第一次用的时候克隆一次、之后一直留着，之后每帧只改 uniform，
**不触发任何 shader 重编译**。折叠/展开、换主题这些路径上也不会漏——探针重新绑定时会连
正在渐变中的副本一起更新。

标记（右侧列表的行、底部那排刻度）也是**建一次、之后只切 class**，不再每次重新生成：
新建的元素一出生就是终态，过渡动画根本不会播，那才是切编号时"跳一下"的来源。

## URL 状态（便于截图/分享）

```
index.html?v=front&x=1&f=1&t=studio&p=1&r=04&ui=0
```
`v` = iso|front|top|detail，`x=1` 拆解，`f=1` 翻转，`t` = noir|studio|toon，`p=1` 播放，
`r=03` 直接打开该编号的档案，`spin=0` 关掉自动巡览，`ui=0` 隐藏界面，`intro=1` 强制播放片头，
`fps=1` 显示帧率 / 每帧 JS 耗时 / 当前 dpr / 主体的横向偏移量（`off 当前值→目标值`，调构图时用）。
`x=1`、`f=1` 与 `r=` 都是**即时落位**的（不走过渡动画），方便截图。
`intro=1` 时片头拥有镜头，`v=` 与 `r=` 自带的机位不再抢占它（其余状态照常生效，所以
`?intro=1&r=03` 是"放片头，同时把 03 号档案打开"）。

## 画面

- **1.25× 超采样**：后期链路按 1.25 倍渲染、最后一级缩采样，边缘质量接近 4×SSAA；显存吃紧时（>9M 像素）自动关掉。
- **镜头感**：全屏 pass 里做了距主体越远越糊的 9 抽样散焦（大光圈感）、径向色散、暗角、颗粒，
  加上胶片式分离色调（暗部偏冷/高光偏暖）和最亮高光的暖色溢出（halation）。
- **环境与光**：PMREM 里塞了 7~9 块 HDR 柔光板（主光、冷暖侧条、顶部补光、两颗小 kicker 出锐利高光点），
  环境贴图每帧极慢自转，高光会在壳面上缓缓游走而不是钉死。
- 2048 阴影贴图 + 软 PCF、雾一样的双层尘埃（一层实、一层大颗粒虚焦 bokeh）。
  尘埃飘到顶会回收到底部，两头都按高度淡出，所以看不到粒子"闪一下换个地方"。
- **实时地面镜像**：每帧在主渲染前用镜像相机渲染一次场景到 RT，采样时沿屏幕 Y 做 13 抽样高斯拖影
  （抛光石地板的反射是竖向拉伸的），再叠距离衰减与掠射角增强。没用 three 的 `Reflector` 插件——
  它的 `onBeforeRender` 会在玻璃的透射通道里再次触发，导致渲染器 `setRenderTarget` 重入（实测直接把浏览器窗口搞崩），
  自己算反而干净，还能在低性能设备上一键关掉（降质时先关它）。
- **片头**：磁带一开始**停在地板上**（0.7 秒，够看清它是"放"在那儿的），然后**线性带阻尼**地悬浮到它该在的
  高度——线性走完大部分行程，最后一段交给缓出，所以是"升上来"而不是"被电梯送到"。它不再从地板底下穿上来：
  从下面出来的话，前面两秒整个主体都在往一张它不该穿过的平面里挤，而这是这个场景别的地方都很在意的事。
  镜头同时在 3.4 秒里从更远更低的机位推回默认机位，带盘在上升时还在转。
- **投影接收面**：`ShadowMaterial` 叠在镜像之上（renderOrder 控制次序），影子会连反射一起压暗。
- 主体背后一层暖色辉光墙给虚空补纵深、地板上一圈暖色光池。

调试用：URL 加 `?fps=1` 会在顶部显示实时帧率 / 每帧 JS 耗时 / 当前 dpr / 镜像开关 / 主体横向偏移。


## 灯光（按摄影棚逻辑布）

`src/lights.js` 里是一套照片级的五灯位，不是"3D 场景灯"：

| 灯位 | 作用 | 实现 |
| --- | --- | --- |
| key | 主光，相机轴 45° 偏左、仰角约 33°，暖色 | `RectAreaLight` 9×6 |
| fill | 副光，反侧、贴近相机轴、大而弱、偏冷 | `RectAreaLight` 12×8 |
| rim | 轮廓光，背后窄条，勾出剪影 | `RectAreaLight` 1.3×13 |
| bounce | 桌面白卡反弹，抬起底部暗部，暖色 | `RectAreaLight` 12×12（低位） |
| top | 顶部大面积补光，保证标签面可读 | `RectAreaLight` 12×12（高位） |
| shadow | 只负责投影（柔光箱不投影） | 与 key 同位的 `DirectionalLight` |

关键点：**`RectAreaLight` 是 three 里唯一像柔光箱的光源**（矩形即发光体，所以光滑壳面上会出现柔光箱本身的矩形高光，
衰减也符合面积光的物理），但它**不能投影**，所以用一盏同方向的平行光专门丢投影。
主光/副光的强度比 ≈ 4:1，色温上主光偏暖、副光与轮廓光偏冷——这是摄影里控制立体感与分离度的基本手段。

背景用一张烘焙好的"无缝背景纸"贴图：竖直渐变 + 主体正后方一团柔和的背景光（真实背景灯打在背景纸上的效果），
其中渐变与地面同色，所以看不到地平线的接缝。切换光环境时，五盏灯的位置、尺寸、色温、强度会一起过渡，
像是灯架被推着换位。

这套过渡走的是**一条线性时钟**，不是指数衰减。指数衰减前三分之一秒就把大部分行程走完了：往亮里切几乎看不出来，
往暗里切就成了"灯被掐了"——影棚切暗房就是这么被读成**突然变暗**的。现在灯、曝光、后期、地面色和背景一起按
一条两端缓入缓出的线性进度走 1.6 秒。每个值要走的距离都不一样，所以能共享的不是速率而是**进度**：
对 `dx/dt = rate·(target − x)` 取 `rate = p′/(1 − q)`，解出来正好是 `x = x₀ + (target − x₀)·q`——
所有值都落在同一条 `q(p)` 上，颜色、灯光、透明度因此始终同步。

背景纸是烘焙死的、没有中间态，直接换贴图就是一次硬切——而这是全屏面积最大的一块。所以换环境时是
**第二张球壳把新背景淡上来**（两张都是 `BackSide` + 不写深度，只有绘制顺序说话：不透明的那张先画，
新的透明那张后叠上去），淡完新贴图才提为底图。灯位、曝光、后期参数本来就是缓动，背景跟上之后
整段换环境就没有硬切了，原先那记"快门压暗"因此删掉。

反射探针换环境时会重拍一次。灯的缓动不影响它（探针拍的是灯架那几块面板的几何，而面板在切主题那一刻
就已经是新环境的了），**背景**影响它——所以抓拍的那一瞬间会把背景**临时推到终态**再拍、拍完放回去，
六面立方体是同步渲染的，除了探针没人看得见。这一下本身还是瞬变，没有缓动：PMREM 就是
一张纹理，换纹理是一次赋值，想真的渐变就得把两代 IBL 逐像素混起来，为一步动作上一套乒乓 RT 不划算。
但它现在既不会**当着人**换，磁带也不会在过渡中间变暗：房间变化期间，**磁带手里握的光始终等于此刻房间的亮度**
（`envMapIntensity` 沿着背景自己的交叉溶解曲线走，`(s(t)/s_ref)^2.2`，`s` 是背景在 sRGB 下的平均亮度——
两间屋子交叉本来就是 sRGB 值的 alpha 混合，所以走的就是那个空间）。手里那个探针是旧房间的还是新房间的
都无所谓，强度会把差额补上。

所以换探针那一帧变的不是亮度，而是"反射的是哪间屋子"，那就挑**反射最暗的一帧**换：变暗时是变化的末端，
变亮时当下就是。这样弹的那一下（图案，而非亮度）发生在没人看的时候。抓拍时还会临时把抓力推回 1——否则
探针会把一台"没有环境光"的磁带烤进它自己以后的每一次自反射里。

三套光环境里「影棚」是默认：主副光比 2:1，冷灰背景，用来核对材质与印刷。

## 环境光遮蔽与自反射

**AO（`src/ao.js`）**：自己写的屏幕空间遮蔽，**全分辨率 + 双尺度 + 双边滤波**：

- 一个 tap 预算里跑两个半径——**近半径 0.17**（螺钉沉孔、磁带缝这种贴合的暗角）和
  **远半径 0.85**（窗口、轮毂开口里的大块遮蔽），各自有独立强度与偏置
- 去噪用**可分离的双边滤波**（横向 + 纵向各 9 tap，按视空间深度差加权），
  所以噪点被抹掉而遮蔽不会糊过轮廓——廉价 SSAO 那种"整体蒙灰"就是这么来的
- 每像素旋转是**固定**的（随时间变化会拿色带换时间性噪点，表现为折缝上的高频闪烁）
- 末端一个**时间累积 pass**：拿上一帧的相机矩阵把当前像素重投影回上一帧，深度校验后混合，
  并钳制在当前帧 3×3 邻域内

整套加起来约 6 个全屏 pass，GPU 上大约 1 ms 级——这台机器上 GPU 本来就在闲着。


**自反射与物体间反射（`src/probe.js`）**：一颗 512² 的反射探针。
把柔光板做成**真实几何但只挂在 layer 2**（主相机和镜像相机都看不到），探针相机额外开启该层，
于是探针一次就同时拍到"灯架 + 磁带自己 + 地面"，经 PMREM 滤波后作为所有机身材质的 `envMap` ——
镀铬导带柱、金属屏蔽片、烟灰玻璃、高光壳面因此会映出相邻零件，而不只是环境。
探针放在壳体左上前方（物体外部），翻面/拆解/换主题后自动重拍。

没有用 SSR：three 的 `SSRPass` 每帧会重渲染两遍场景（自身 beauty + 法线），正好把性能优化抵消掉；
探针方案的代价是视差近似（方向准确、位置是单点采样），但对这种尺度已经够用。

## 三渲二（「动画」主题）

第三个主题把实时管线转成偏日式动画的风格，做法全部在最终调色 pass 里（`src/post.js` 的 Grade），不动材质：

- **描线**：两路信号合成。一路是**视空间深度台阶**（阈值随距离缩放，所以斜着的表面不会自己长出线），
  用来勾外壳对地面／对虚空的剪影；另一路是**深度导数重建的法线突变**，用来勾贴合零件之间的折缝
  （标签边缘、窗口内沿、磁带缝）。两者取最大，乘上墨色叠加。
- **亮度分层**：把明暗压成 4 阶，采样值上加一点点哈希抖动避免渐变色带，再按亮度比例缩放颜色以保住色相。
- 配一套**平光高调灯位**（`RIG.toon`，主副光比约 1:1），配合降低 bloom / 色散 / 暗角，让分层更干净。

关键的一个坑：玻璃、尘埃都是透明材质**不写深度**，那些像素处 `d0 = 1`，
用它重建法线会得到 NaN，而 NaN 能穿过 `clamp()` 和 `mix()` 变成随机黑点——
所以 toon 阶段对没有深度的像素直接早退，法线也只在与邻域都是实体时才计算。

**AO 高频闪烁的成因**（三个，都已修）：

1. **合成器的深度纹理每两帧才更新一次。** `EffectComposer` 把传入的 render target 克隆一份当读写缓冲，
   而 three 的 `WebGLRenderTarget.copy()` **连深度贴图一起克隆**（`three.core.js`）。`RenderPass` 画进哪个
   缓冲由 `readBuffer` 决定，而这条 pass 链每帧 swap 次数是 3（AO / Output / Grade，奇数），所以
   `readBuffer` 每帧在两张 RT 之间来回切——偶数帧 AO 采到当帧深度，奇数帧采到的却是上一帧的。
   主体每帧只漂 0.08 px，于是遮蔽图案以半帧率在「正确」和「滞后一帧」两张图之间反复横跳，
   每条边都在抖。修法：让两张 RT **共用同一张深度纹理**（`post.js` 一行）。
   同一个坑也影响 `grade` 里那条深度描边。
2. **法线来自 `dFdx/dFdy`。** 深度贴图是 MSAA **resolve** 出来的（`blitFramebuffer(..., NEAREST)`，
   每像素只取一个采样），轮廓处邻像素会在「物体」和「背景」之间跳。一个邻像素跳了，重建出的
   空间位置落到远平面，`cross(dFdx, dFdy)` 跟着翻，整片 2×2 quad 的半球基向量一起歪 → 遮蔽量整体跳。
   修法：邻域 tap 与中心深度差超阈值就**收敛到中心**，跳变变成空操作。
3. **遮蔽判定是阶跃。** `diff > bias ? 1.0 : 0.0`——任何深度变化，哪怕是远小于一个像素的漂移，
   都能让一个采样点从「完全遮蔽」翻到「完全不遮蔽」。改成两端都平滑的 ramp。
   以上两条都消不掉**轮廓本身**的锯齿（它就是一个像素一个像素地跳），所以末端再加时间累积：
   重投影 + 深度校验 + 邻域钳制，既压掉跳变又不会在拆解、走带这些真实变化上拖影。

## 关于“材质正确”的几处实现

- **外壳**：烟灰聚碳酸酯 = 低粗糙度 + clearcoat；侧壁用另一套更粗糙的模具面材质，
  叠程序化法线图模拟细皮纹，接缝处刻意留 0.03 的台阶（真实双片壳体就是这样合的）。
- **边**：能看见的直角都留了倒角，且整套几何走**自动平滑着色**。
  倒角是几何而不是着色技巧：挤压件用 `bevelSize`（上下壳 0.03、模具前框 0.022、
  角件 0.018），圆柱件的端面倒角则用 `latheCyl()` 车出来——`CylinderGeometry` 的
  端面与侧壁是真正的 90°，而真正的 90° 边**不产生任何高光**，看上去像纸板。
  轮毂干脆改成一条闭合剖面回转（`hubShell()`）：外壁、轴孔、上下两个端环和四道倒角
  是一个曲面，不再需要"三块拼起来 + 把轴孔翻面"。
  着色侧：`ExtrudeGeometry` 交回来的是平直着色的三角形（它自己对非索引缓冲做
  `computeVertexNormals`，只能得到面法线），于是所有圆角都在按段折线走、倒角是一条棱。
  现在统一过 `toCreasedNormals(g, 35°)`（`autoSmooth()`）：比 35° 浅的棱两侧法线合并、
  比它陡的保持硬边——90° 的真角还是角，rrect 的圆弧（每段 9°）和倒角自己（30°）
  则滚成一条高光。代价可忽略：最大的那块壳板 6048 顶点，5 ms。
- **观察窗**：烟灰玻璃用「透明 + 清漆」而不是 `transmission`。真折射会让 three 把不透明物体
  再渲染进一张单独 RT（每帧多一整遍场景），而 0.055 的厚度下折射本来就看不出来——观感几乎一致，代价差一整遍。
- **磁带**：γ-Fe₂O₃ 磁层用 sheen 表现绒面反光，带盘顶面是同心层纹贴图，侧面是光滑的带边。
  带条的截面方向是关键——**3.81 mm 的宽度永远沿机身厚度方向（Y 轴）竖直**，只有 12 µm 的厚度沿轨迹法线方向，
  这样磁层面才会正对磁头开口；写反会变成一条平躺的板子（顶面朝上反光）。
- **金属**：拉丝粗糙度贴图 + `anisotropy`，螺钉为沉头十字槽。
- **纸张**：纸标有噪点法线、sheen、轻微 clearcoat（覆膜感），低环境反射。标面本身是
  一张水彩，但**不是画上去的，是算出来的**：见下面「水墨晕染」。两面共用一个纸纹场，
  但各走各的显影：A 面三遍 glaze 正片叠底到纸白上，B 面是同一张画滤色到深底上——
  深底靠发光被读、浅纸靠明度被读。B 面仍走旧的 `dissolve()`（轮廓团 + 噪声取阈值），
  它要的正是那种「糊成一片光」的效果。

  还有一条构图上的要点：贴纸被观察到的不是整张纸，而是**窗口镂空之后剩下的边框**（左右两条
  窄边 + 上下两条带）。所以颜料要**在可见边框内侧最浓、到窗口切边前就淡掉**；画在纸中央的
  团块会被裁掉大半，剩下的一点落在角上像块污渍，切口还留下一条直边。标题用 Gabriola 手写体，
  铜色横带已换成手画的墨线。
- **走带**：恒定线速度 4.76 cm/s，两带盘角速度 ω = v/r，带面积守恒（`A_L + A_R = const`），
  磁带包角与切点每帧按外切线解析求解后重建带条几何。
- **轮毂转动**：六个齿朝向中心孔内伸（外径 12 mm、内孔 ⌀7 mm 的真实比例），从上方能直接看到齿在转；
  带盘顶面额外画了一道极淡的螺旋接缝和卷带末端台阶，打破旋转对称，让带盘自身的转动也看得出来。
  转速由 `ω = -(dA/dt)/(层厚·r)` 反推，所以播放、快倒、外部音频驱动三种来源都自动正确。
- **色彩**：Linear 工作空间 + Neutral tone mapping + 线性 HDR bloom，颗粒/暗角在色调映射之后叠加。

## 水墨晕染（A 面那张水彩是怎么来的）

先说为什么不能"画"：把一片水彩画成一个**有柔边的形状**，得到的是喷枪——一个均匀的色调、
一条均匀的衰减、一个因为画得圆所以圆的外轮廓。水彩不是形状，是**水在纸里走，颜料留在水停下的地方**。
所以不是画，是模拟：`src/textures.js` 里 448×276 的小格子上跑一遍，画出来的东西只是这次流动的记录。

五条规则，每条都很便宜：

1. **纸有三层尺度**。`perm` 是这一格多能吸水，`fib` 是两组正交拉伸的噪声、代表纤维走向，
   `fine` 是纸纹。于是轮廓在三个尺度上**同步地**毛起来——那些须是跟着场走的。
   这一点是「噪声过阈值」永远做不到的：那里的毛是逐像素的，看着像脏，不像纸。
2. **会冻住的湿边**。一格只要有压强（`wi·give`）压过纸的阻力，就把水递给外面一格；
   能不能过这一格由纸纹决定，而压强只减不增（蒸发）。于是边界像潮线一样各自停在不同的时刻。
3. **颜料跟着水走**（donor-cell upwind）。光这一条就会把颜料堆到边上，加上"干掉的那格把
   还攥着的一把颜料扔下"，深色的**水痕**就自己出来了——不是画出来的。
4. **沉积与重新溶解**。水膜变薄，颜料析出；后来再有水到，又把它拎起来。于是**在快干的洗色上
   滴一滴清水**，它会把颜料拎起来往外推，形成中间浅、四周有丝的开花——就是一般人说的"晕染"，
   渐变是拿不到这个的。
5. **两种颜料**。水彩会分层：重的颗粒留在原地，轻的跟着水走得更远、干了以后是一圈更宽的冷调
   光晕。同一个水里带两种，一片洗色才有"芯 + 晕"，而不是一个平调子。

一遍 glaze 跑完是 400 ms 上下，A 面三遍（蓝灰场、青调、暖调）≈ 0.7 s，只算一次。
改浓度看 `DAY_LOAD` / `DAY_DENSITY`，改构图看 `DAY_GLAZES` 里那几笔（都是纸面比例）。
调试时可以用 `tools/_ink.mjs`——同样的算法在 Node 里跑，直接把结果写成 PNG，不用开浏览器。

## 设置

页头 **SETTINGS**（或 `,`）打开一张五行的设置页——用的就是总目录那套浮层，一行一个开关：

| 开关 | 它接的是页面里本来就有的什么 |
| --- | --- |
| **开场动画** | 打开时那 3.4 秒的推轨与浮起（= `?intro=0`）。**下次打开生效**，它只在启动时读一次 |
| **循环播放** | 放完自动倒带重放（`ended` → 倒带 → 再放）。关掉的话磁带**照样倒回开头**，只是倒完停在那儿，计数器回 `00:00`，按钮回到「走带」 |
| **磁带底噪** | 走带时的嘶声与马达嗡声（`bedLevel()`）。换向声、旋钮声不受影响，它们走的是另一条母线 |
| **按键提示** | 底部那行快捷键说明（`body.keys-off` 把 `.hud-c` 收起来） |
| **地面镜像** | 地面那遍实时反射（`floorBase`）。关掉能省一整遍场景渲染——性能守护程序本来也会先砍它，这个开关是同一件事的手动版，两者取「与」 |
| **暗角** | 画面四周压暗的那一层（后期链里的 `uVig`）。**默认关**。它不是一个独立的值：开关决定 `applyTheme()` 里那条目标，所以关掉是**淡出**而不是瞬间消失，主题切换也照旧——开着的时候三个房间各自用自己的强度（暗房/影棚 0.85，动画 0.48） |

开关记在 `localStorage`（键 `ohmtape.prefs`，读写都裹了 try/catch，存储被禁用就退回默认值）。
**只有设置会跨刷新保留**——音乐是故意不保留的（见「音乐」）。
